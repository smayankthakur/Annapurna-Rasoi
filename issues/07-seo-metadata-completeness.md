# Issue 7: SEO Metadata Completeness

## Description

Metadata consistency across pages requires improvement for better indexing and social previews.

## Steps to Reproduce

1. Inspect each page `<head>`.
2. Verify title, meta description, canonical, Open Graph, and Twitter Card tags.

## Expected Behavior

All indexable pages include complete, unique, and consistent SEO metadata.

## Actual Behavior

Metadata is missing or inconsistent on some pages.

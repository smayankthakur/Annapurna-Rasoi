# Issue 5: Accessibility Audit and Remediation

## Description

Accessibility semantics and interaction support need stronger consistency across pages.

1. Run keyboard-only navigation.
2. Inspect semantic regions, ARIA attributes, alt text, and form labels.

## Expected Behavior

Semantic landmarks, descriptive alt text, form labels, keyboard support, and clear focus states are present.

## Actual Behavior
